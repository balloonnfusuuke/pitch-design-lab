# ピッチデザイン・ラボ

投手の握り、指の力、腕の振りから変化球を設計し、マウンドから本塁までの軌道を見るための実験室です。ブラウザだけで動き、空力の計算は TypeScript に置いてあります。

## 起動

```bash
npm install
npm test
npm run dev
```

開発サーバは [http://127.0.0.1:3847](http://127.0.0.1:3847) です。

静的サイトとして書き出す場合:

```bash
npm run build
```

`out/` ができます。Vercel では Next.js プロジェクトとしてデプロイでき、`output: "export"` のため追加のサーバは要りません。

## 画面でできること

- 8 球種のプリセット（フォーシーム、ツーシーム、カッター、スライダー、スイーパー、カーブ、チェンジアップ、スプリット）
- 指ごとの力、最後に離れる指、アームスロット、手先の速度、回内・回外、手首の伸展・屈曲、リリースのタイミング
- 狙い、エクステンション、身長、気温、標高、縫い目ウェイクの強さ
- 3D の軌道（斜め / 捕手 / 投手 / 横 / 上）。ボールの縫い目は回転し、金色の矢印がスピン軸
- 灰色の線は、回転も縫い目もない場合の軌道。そこからの差が IVB と横変化
- 複数球の重ね合わせと、本塁 6.4 m 手前（判断点）での間隔
- 目標の変化から握りと腕を探す逆設計。可動域の端に当たった項目をトレーニングのヒントにする
- 写真と「手首から中指の先」の長さから指の節を測り、トルクのレバーに使う
- Rapsodo / TrackMan 風 CSV と、今の設計との差

横変化の符号は捕手から見て右がプラスです。右投手のアームサイドはマイナス、グラブサイドはプラス。画面には「アームサイド / グラブサイド」とも出します。時計は投手から見て、12 時がバックスピン、3 時が投手の右手側です。

## 物理として根拠がある部分

軌道の積分は、重力、抗力、マグヌス力です。

- ボールは質量 0.145 kg、円周 9.125 in
- 揚力係数は Alan Nathan の 2020 年更新式です。`CL = 0.336 (1 − exp(−6.041 S))`。`S = r ω_T / v` で、`ω_T` は速度に垂直な回転だけです。出典は Nathan, “Determining the 3D Spin Axis from Statcast Data”（2020-05 更新）の式 (8)
- 空気密度は 15°C・海面で 1.225 kg/m³ を基準に、気温と標高（スケールハイト 8500 m）で変えます
- 本塁はラバーから 60.5 ft。IVB / 横変化は、同じ初速で抗力と重力だけの軌道との差です
- テストは、典型的なフォーシーム、シンカー、スライダー、スイーパー、カーブ、チェンジアップの速度・回転・軸を直接入れ、変化の向きと大きさが公開されている帯に入ることを見ています。真空で水平に投げた球は `½gt²` だけ落ちます

| --- | --- | --- | --- | --- | --- | --- | --- |
| フォーシーム | 95 mph | 87 | 2200 rpm | 95% | 12:45 | +21 in | −8 in |

フォーシームの IVB は平均的な MLB より上で、回転効率が高く軸が立っているときの「よく伸びる速球」です。平均の 16 in 前後は、効率を下げるか軸を倒すと近づきます。

## 近似している部分

抗力係数に、Nathan の CL のような一つの確定式はありません。投球速度で報告されてきたおおよそ 0.30–0.40 を通る滑らかな曲線です。95 mph 付近で約 0.33 になり、フォーシームは本塁までに 6–11 mph 落ちます。

ブラウザのリリースモデルは透明な運動学です。画面の球種は、この式で出しています。

- 回転数は `接線力 × 半径 × 接触時間 / 慣性モーメント`。慣性は一様球の `0.4 m r²`
- 指 1 本の接線力の上限（42 N）と接触時間（約 7–11 ms）は、上の表に着地するよう合わせた値です。腱の張力を測ってはいません
- スピン軸は「前腕とほぼ直交する」という投球の観察（Jinji & Sakurai 系）を、スロット・回内・手首のルールに落としています。筋骨格のシミュレータではありません
- 回内のプラスは、利き腕のアームサイドに軸が倒れる向きです。左投げは符号を反転しています
- 縫い目ウェイクは、握りごとの向きと係数を足した項です。縫い目周りの流れは解いていません。強さを 0 にすると消えます
- スピンの減衰は時定数 30 秒の指数減衰で、0.4 秒の飛行では約 1% です
- 写真の手は MediaPipe Hands の 21 点を、入力した長さでスケールしただけです。正面に近い写真が前提で、骨長の計測ではありません。WASM は jsDelivr から読みます。届かないときは指の長さを手入力できます
- ボールの見た目は、軌道の座標を実寸にしたまま、縫い目が見えるよう拡大できます

## MuJoCo のリリース

自由な 6 自由度のボールに、5 本の指（MCP / PIP / DIP、トルク制限つき位置サーボ）と、肩の内旋・肘の伸展・前腕の回内・手首の屈曲を当てます。腕の関節は毎ステップ運動学的に戻します。縫い目は Bourke 曲線上の突起で、縫い目と指の摩擦は接触ペアでその球の縫い目あり μ を直接指定します（形状どうしの最大値合成では縫い目の μ が指パッドに負けて消えるためです）。既定は NPB 統一球の無塗布で 1.0165、`--ball mlb` はロジン条件の 1.107 です。球種で変えるのは握りの姿勢、縫い目の向き、最後まで残す指だけです。速度の倍率は球種ごとに掛けていません。

リリースの姿勢は、掌が本塁（+Y）を向き、指が上を向くように合わせています。前腕はコックした位置（後ろ上方）から、肘の伸展で前に出て、リリースでは頭より前にあります。肩の内旋は Fleisig のピーク 7511 °/s をリリースに置く短いスパイクで、その幅（σ = 3.5 ms）は未公表です。ピーク速度を加速区間のあいだ中かけ続けると手が 100° 以上回り、掌がボールから外れます。回内のピークは Barrentine らの減速期（リリース +17 ms）に置き、接触中にはかけていません。指の関節は過伸展を止めます（MCP は約 8°、PIP と DIP は約 2°。PIP / DIP は掌側板で後ろに折れません）。母指は Stevenson の約 6 ms 前に開き、薬指と小指もその時刻に開きます。人差し指と中指（スライダーは人差し指、チェンジアップは中指と薬指）は Matsuo の 8 ms の転がりまで残します。

この腕はリリース前にボールを横へ振り出すので、転がりが始まるまではボールを掌に乗せて運び、最後の 8 ms とリリース後だけ接触で放します。運んでいるあいだの速度は掌の速度です。

2020 年の NPB 革の実験（Yamaguchi ら, Front Sports Act Living）では、乾燥条件でロジンが μ を必ずしも上げず、ばらつきを抑える、と報告されている。2022 年の MLB 革ではロジンが μ を縫い目なしで 23.9%、縫い目ありで 27.0% 上げた。NPB にその上昇幅を掛けた値（革 1.1876、縫い目 1.2910）は代用で、`--ball npb-rosin` です。既定は測られている無塗布のままです。同じ無塗布どうしでは、NPB は MLB より縫い目ありで 16.6%、縫い目なしで 23.1% 高い。粘着物質はさらに高く（縫い目ありで約 +55%）、禁止物なので入れていません。`--ball mlb` は MLB＋ロジン（縫い目なし 0.965、縫い目あり 1.107）です。

質量は両方とも公認野球規則 3.01（NPB の統一試合球規則も同じ範囲）の 141.7–148.8 g の中点 145.25 g、周囲は 9–9.25 in の中点 9.125 in です。現行ミズノ球のサンプル平均は見つかっていません。反発係数の目標 0.4134（NPB 2015-02-03）はバットでの値で、指の solref には入れていません。縫い目の幅の標準 8.0 mm と 108 針も接触の球の半径には使っていません。縫い目の中心線は両球とも Bourke の式で、NPB も Rawlings も公開された曲線はありません。

指腹の硬さは Serina, Mote, Rempel（J Biomech 1997; 構造モデル 1998）が、1 N 未満で大きく潰れ、5.2 N での変位の 82% が 1 N までに起きる、と測っています。単一のばね定数も MuJoCo の `solref` も出ていません。`solref` の `"0.004 1"` は未公表のソルバ設定です。

### 2024 年 Statcast（右投手）との差

速度・回転・active spin・軸は [スピン方向リーダーボード](https://baseballsavant.mlb.com/leaderboard/spin-direction-pitches?year=2024&min=100) で、その球種を 100 球以上投げた投手を球数で重み付けした平均です。軸の時計は `(180 − spin_axis) mod 360` で、12 時がバックスピンです（Verlander の 2024 年フォーシームは軸 154.7° で 12:45）。IVB と横変化は [カスタムリーダーボード](https://baseballsavant.mlb.com/leaderboard/custom?year=2024&type=pitcher) を、シーズン投球数 × 球種割合で重み付けしています。横変化は Statcast の符号で、捕手から右がプラス、右投手のアームサイドはマイナスです。MLB.com の用語集は 2024 年のフォーシーム IVB を約 +16 in、カーブを約 −10 in としており、上の重み付き平均（+15.8 / −10.1）と揃います。

active spin は Savant の値です。このモデルの効率は `|ω × v̂| / |ω|` で、定義が同じとは限りません。カスタムリーダーボードにスピン効率のリーグ平均列はありません。

MuJoCo のリリース状態を、画面と同じ Nathan の抗力・揚力（縫い目ウェイクなし、22°C）で本塁まで飛ばした結果です。

| フォーシーム | 47.2 | −47.6 | 1139 | −1173 | 4:19 | 1:05 | +97° | 0.79（参照 0.90） | −17.9 | −33.6 | −16.9 | −9.4 |
| カーブ | 42.0 | −38.3 | 1209 | −1407 | 1:58 | 7:27 | −164° | 0.98（参照 0.71） | +24.2 | +34.3 | −31.3 | −40.7 |

参照の球速と回転は、フォーシーム 94.7 mph / 2312 rpm、カーブ 80.3 / 2617、スライダー 86.2 / 2446、チェンジアップ 86.0 / 1844 です。

4 球種とも速度はほぼ +Y（本塁）で、上下成分は小さいです。球速が平均の半分なのは、リリース時の肘屈曲 22° では前腕が内旋軸に近く、モーメントアームが `0.27 × sin(22°)` で約 10 cm だからです。7511 °/s をその半径にかけると約 13 m/s で、体幹の並進を足しても 20 m/s 前後（約 45 mph）です。下の全身モデルでは OBP の計測した動きを体幹と腕のトルクで再現し、球速は 29.5 m/s（29 球の平均）です。以前の表が 80 mph 台だったのは、内旋をピーク速度のまま回し続け、近位速度を 28.7 m/s に合わせて閉じ、指関節の可動域が度数として解釈されてほぼ真っすぐのまま固定されていたためです。いまの回転軸は指の転がりだけでは 1 時台のバックスピンになっておらず、Statcast の IVB とは符号ごと違います。スライダーの効率 0.39 だけが参照の 0.32 に近いです。

## 全身の投球（関節中心の軌道で駆動、データセット不要）

全身モデルの入力は `pitchlab.motion.Motion` です。中身は関節中心 17 点（＋任意の 3 点）の時系列、足着地・MER・リリースの時刻、身長・体重です。既定は「文献の SD 内で整合させた一人の投手」です。OBP は任意の検証用で、既定の経路からは一切読みません。

| 入力 | 使い方 | 中身 |
| --- | --- | --- |
| 一人の投手（既定） | `--motion literature` | `literature.py` と `single_pitcher.json`。文献の平均と SD（Fleisig 博士論文 Table 2、Fleisig ら 1995、Stodden ら 2001、Barrentine ら 1998）を、一人の投手として矛盾しない値に寄せたもの（下記） |
| 文献平均 | `--motion literature-mean` | 全項目を平均値にした以前の参照。比較用 |
| 自分で撮った動き | `--motion csv:PATH,身長m,体重kg` | 列は `time` と `<点>_x/_y/_z`（m、+Y が本塁、+Z が上、+X が投球腕側）。`#MER_time=`・`#BR_time=` の行でイベントを渡す。`pronation_deg`・`pelvis_sup`・上顆 2 点は任意 |
| OBP（任意） | `--motion obp:2916_4`、`--body-validate N` | `PITCHLAB_OBP_ELIGIBLE=1` のときだけ読み込む（キャッシュの読み出しも同じ） |

見つからなかったときの代案として指示されていた「単一投手の運動学から時刻整合した滑らかな参照を作る」を、次の方法で実装しました。

### 一人の投手として整合させる（`pitchlab/pitcher.py`）

平均値どうしを組み合わせた動きは、誰の投球にもなりません。全項目を平均にすると、ボール点の速度はリリースの 13 ms 前に最大になり、その後は下へ曲がります（押し出しから 3 ms 後の進行方向が −45°）。

そこで、各文献値の偏差 \(z_k\)（SD 単位）を 37 個並べ、\(\sum z_k^2\) が最小になる値を探しました。条件は次のとおりで、各 \(|z_k| \le 2.5\) です。

| 条件 | 値 | 由来 |
| --- | --- | --- |
| 押し出し（ボール点の速度最大）がリリースより前 | 10 ms | 研究: Matsuo ら 2018（転がり 8 ± 1 ms）＋検出の 2 ms（推測） |
| 押し出しから 3 ms 後のボール点の向き（上下） | −2.5 ± 1° | Statcast のフォーシームのリリース角（ボール追跡データ）。「3 ms 後」は推測で、シミュレーションの射出方向がこの経路のどこに来るかから決めた |
| 同（左右） | 0 ± 1.5° | 推測（本塁へまっすぐ） |
| 押し出し時のボール点の速さ | 40 ± 1 m/s | Fleisig の 38.3 m/s＋転がりの増分（推測） |
| 第 2 段: シミュレーションの球速・射出角・リリース時刻 | 39.6 ± 1 m/s、上と同じ角度、±2 ms | ステージ 1 の範囲の中央 |
| 第 2 段: 13.4 Hz で処理した肩内旋・肘内反モーメント | 67 ± 11、64 ± 12 N·m | 研究: Fleisig ら 1995（運動学と同じ 26 人） |

結果は \(\sum z^2 = 12.8\)（37 項目、最大 \(|z|\) 1.9）でした。無作為な一人なら期待値は 37 なので、平均から特に離れた投手ではありません。大きく動いた値は次のとおりです。

| 項目 | 文献 | この投手 | z |
| --- | --- | --- | --- |
| リリース時の体幹前傾 | 37 ± 6° | 26° | −1.9 |
| 手首屈曲速度のピーク | 2954 ± 789 °/s | 1720 °/s | −1.6 |
| MER | 179 ± 8° | 188° | +1.2 |
| リリース時の肩の線の向き（90° で本塁向き） | 111 ± 7.3°（Stodden） | 104° | +1.0 |
| 加速期の水平内転 | 18 ± 7° | 11° | −0.9 |

注意点が 2 つあります。

- 射出角は、条件として Statcast の値を入れています。そのため、ステージ 1 の射出角の判定は独立した予測ではありません。それでもシミュレーションでは、指と球の接触を通してこの値を再現する必要があります。
- 第 2 段では Fleisig 1995 の負荷も条件に入れました。したがって、負荷の判定は「その運動学で Fleisig の運動力学にどこまで近づけるか」を測るものになっています。

再計算は `python -m pitchlab.pitcher`（第 1 段、運動学だけ、約 15 分）と `python -m pitchlab.pitcher --refine`（第 2 段、シミュレーション、約 6 分）で行います。

### 体幹と骨盤

- 骨盤に前傾・側傾の自由度を足しました（任意の点 `pelvis_sup`、`imitate._level_pelvis`）。
- 文献の参照では、脊柱をまっすぐ（推測）として、骨盤にも胸郭と同じ傾きを与えます。
- これで「股関節中心→胸郭上端の線」（Fleisig と OBP の測り方）と胸郭分節が、両方とも 37°/31° になります（`test_hip_to_thorax_line_has_the_published_tilt_too`）。
- 公開曲線を追従していた投球のリリースは前傾 26°・側屈 35° でした（目標は z で動かした後の 25.5°/35.9°）。iter17 は着地後の体幹を 12 Hz で保持しており、リリース時の体幹は前傾 10°、側屈 21°、回旋 −10° です。

### モデル

```
骨盤（自由）─ 腰椎（球）─ 中胴 ─ 胸椎（球）─ 上胴＋頭
  │                                 ├─ 肩甲帯 sc_prot・sc_elev ─ 肩（球）─ 肘 ─ 回内 ─ 手首 屈曲・橈尺屈 ─ 手（5 本指）
  │                                 └─ グラブ側の肩甲帯 ─ 肩 ─ 肘 ─ グラブ
  └─ 股（球）─ 膝 ─ 足首
```

- 分節の物性は de Leva（1996、体幹 3 分節）と Veeger（1991、肩甲帯）です。
- 着地より前は骨盤と両脚を運動学で書き戻します。着地以降は骨盤の並進力を 0 にし、脚は着地位置へ届く姿勢への 12 Hz PD です。膝は伸展 250 / 屈曲 200 N·m、股は両脚とも 400 N·m、足首は 160 N·m で切ります。骨盤の回転は 12 Hz を 600 N·m で切ります。体幹と肩は着地前 40 Hz、着地後 12 Hz に参照加速度を足します。回内は Formica らの受動剛性と 4 N·m/rad の弱いばねです。手首の屈曲と尺屈は、その上に DiGiovine らの位相に合わせた開ループのトルクを足し、Delp の箱で切ります。肘はロール窓だけ、Holzbaur の箱で切った逆動力学です。足の球はマウンドに 1 mm 重なり、solref は 0.03 s です。着地後は鉛直床反力が出ます。
- 負荷は `cfrc_int` から取り、比べる相手と同じ処理をしてからピークを取ります。OBP の球には 20 Hz、Fleisig には 13.4 Hz（Winter の 2 次往復）です。

指とボールは、指腹で持つ握り、押し出しの 9.0 ms 前から指を文献のトルク上限で転がすこと、親指・薬指・小指がロール開始の 2 ms 後に開くこと、を使います。9.0 ms は Matsuo ら（2018）の 8 ± 1 ms の上端です。

### 運びのトップスピンは、実投手では起きていない

Yamaguchi・Suzuki・Nishi・Fukuda・Nasu ら（Scientific Reports, 2025, s41598-025-93632-y）は、セミプロ 6 人のフォーシームを 2000 fps で撮っています。親指が離れる時刻（t = −8.0 ms）の群平均の球角速度はほぼ 0 rad/s で、その後リリースの 1〜2 ms 前まで増えます。ロジン条件の最大は 225.7 ± 10.2 rad/s（約 2160 rpm）、水で縫い目に引っかからない条件は 160.6 ± 27.9 rad/s（約 1530 rpm）です。運びの間に約 1100 rpm のトップスピンが乗ってからバックスピンで打ち消す、という経過は、この計測にはありません。回転はロールの窓の中だけで生まれます。

モデルでその 1100 rpm がどこから来るかを、同じ一人の投手で一つずつ外して見ました。

| 候補 | 何を見たか | 結果 | 切り分け |

指先の滑りは、ロールの後半で下向きかつ横（横成分 0.5 前後）です。摩擦の向きがバックスピン軸から外れ、Yamaguchi らが縫い目の引っかかりで滑りを止めている区間を、この接触は再現していません。回内を ±40° 動かすと軸は 1 時を通りますが、球速が 37.5 m/s を下回るか、軸がトップスピン側へ倒れます。採用していません。

採用したのは、射出角を ±1 ms に対して頑健にするための、文献の範囲の中の 3 点だけです。回転数を上げる変更ではありません。

- 手首の伸展を 40° から 38° へ（Barrentine 1998 の 41 ± 8° の中）。
- リリース後の水平内転（Fleisig の 6 ± 8°、サイクルの 108%）を −0.60 SD から −0.20 SD へ、平均に寄せた。
- ロール開始を押し出しの 8.0 ms 前から 8.5 ms 前へ（Matsuo の 8 ± 1 ms の中）。

ロール開始を ±1 ms ずらしたとき（今回の投手）:

| −1.0 ms | 39.7 | 1260 | 1:39 | −1.7° | −4.3° | はい |
| 0 | 39.4 | 1521 | 1:00 | −3.0° | −4.3° | はい |

### 肩の負荷と腕の経路

上の ±1 ms の表（1040〜1521 rpm、肩 99 N·m）は、剛体指腹の 1 球です。今の馬蹄の握りの数値は、上のステージ 1 の表です。MER は 185° のまま、体幹の前傾は 26°（文献平均 37 ± 6° の −1.9 SD）です。手首伸展は 41.5°、肩は 112.9 N·m（1.685 倍）、肘の内反は 92.3 N·m（1.442 倍）です。

モーメントのピークは足着地からリリースの 82% にあり、Fleisig の 62%（MER より前）より遅いです。この時刻は適合の条件に入れていません。

### 文献の SD から引いた 8 人（シード 1）

前回の 8 人は、公表されている平均を変数ごとに独立に N(平均, SD) から引いただけでした。それは一人の投手の 1 球ではありません。押し出しの速さと向きが別々の論文の平均なので、球速は 27〜75 m/s、回転は 6405 rpm まで広がりました。

今回は、その引き方を各人の事前分布にして、一人の投手と同じ最小化をかけました。目的は、その人の z からの二乗距離と、押し出しがリリースの 10 ms 前・ボール点が本塁方向へ約 40 m/s、です。各 z は ±2.5 SD に収めます。平均へ寄せるのとは違います。8 人が同じ z に潰れないようにするためです。

運動学の代理（ボール点）はこの条件にほぼ入ります。接触まで入れた球は、まだボール点どおりには離れません。

| 基準 | 前回（独立な引き） | 今回（各人を整合） | 判定 |
| --- | --- | --- | --- |
| 射出角（上下） | −13.4 ± 20.1° | +8.0 ± 11.8°（−7〜+26°） | 不合格 |

一人の投手には、この後に接触シミュレーションへ合わせる第 2 段階があります。8 人にも、体幹の傾き・水平内転・手首の角速度の 4 つだけを 2 回動かして同じことをしました。球速は 35.3〜41.5 m/s（39.1 ± 2.0。平均は合格）まで揃います。射出・軸・負荷は揃いません。1 人は接触が不安定になり、回転 8614 rpm、左右 −50° です。第 2 段階を一人の投手と同じ回数（腕の 10 変数、6 反復）まで回すと、1 回のヤコビアンが接触シミュレーション 10 本です。今回はそこまでやっていません。広がりの主因は「平均を独立に引いたこと」で、球速については整合でかなり消えます。残る射出と負荷のばらつきは、指がボール点の速度を再現しないことです。

- 下の感度表は、手首伸展 35°・指トルク 1 倍の一人の投手のものです。今回の ±1 ms は、上の「運びのトップスピン」の表です。射出角は ±1 ms で基準の中に残ります。回転数は 1040〜1521 rpm です。
- **回転数と軸は、いまも接触の扱いに強く依存します。** いちばん効くのは接触の剛性（solref、未公表の solver 設定）で、0.004 → 0.008 s で軸が 4:30 まで回ります。その次が指トルク上限です。摩擦の効きは ±10% 程度です。ロール開始 ±1 ms では 909〜1355 rpm、軸は 12:26〜1:49 です。
- **回転数は、指の力を強めて合わせられるものではありません。** 既定のままでも、指腹の合力は押し出しの前後で 125〜200 N あります。Kinoshita ら（2017）の実測は中指 89.6 ± 18.5 N、せん断 47.3 ± 16.4 N で、モデルのほうがすでに強いです。トルク上限を 2 倍にすると 2444 rpm になりますが、射出角が +8.9° に外れ、力も実測の 2 倍を超えます。そのため採用しませんでした。足りないのは力の大きさではなく、球に回転を与える向き（球の後ろ上をせん断で掃く幾何）だと考えています。

### 負荷の参照: Fleisig と OBP

| 項目 | Fleisig ら 1995（博士論文の方法） | OBP（Driveline） |
| --- | --- | --- |
| 対象 | 熟練した成人 26 人、平均体重 864 N・体重×身長 1620 N·m（88 kg・1.875 m） | 大学〜プロ 100 人 |
| マーカー | 分節あたり 1〜2 個。長軸回りの回旋は直接測れず、前腕の回内外トルクは計算不能と明記 | 全身マーカーで 6 自由度の分節 |

| 平均の取り方 | 各投手の 3 球を足着地とリリースで時刻をそろえて平均し、群で平均 | 1 球ごとのピーク |

同じ論文の表でも、先行研究の値は肩内旋 90 ± 20 N·m、肘内反 100〜120 N·m です。ASMI の最近のプロ投手のデータ（13.4 Hz、4 次、240 Hz）では、肘内反が体重×身長の 5.33 ± 0.74%（この体格で約 85 N·m）でした。Dowling・Slowik・Fleisig（Sports Biomech 2026）は、トルクはフィルタ周波数に最も敏感な変数の一つだと報告し、18 Hz を推奨しています。モデルでも 20 Hz と 13.4 Hz で 3 割以上違いました。

**参照は Fleisig 1995、モデル側は 13.4 Hz で確定。** 1.5 倍は変えていません。

- 既定の運動学が Fleisig の同じ 26 人の値なので、同じ母集団の運動力学と比べるのが筋です。体格もほぼ同じです。
- OBP は、あなたの立場では検証にも使えない可能性が高いです。
- OBP との差の多くは方法（フィルタ、分節の自由度、時刻をそろえた平均がピークを削ること）で説明できます。そのため、モデルをどちらかの処理にそろえずに倍率を見るのは公平ではありません。
- 合格の倍率（1.5 倍）は変えていません。残る差のうち、時刻をそろえた平均と長軸回旋の未計測による部分は、モデルでは再現していません。どちらも Fleisig の値を下げる方向に働くので、判定はむしろ厳しめです。

## フォーシームの握りと NPB 統一球

既定の球は NPB 統一球（ミズノ）、無塗布です。`--ball npb-rosin` はロジン上昇幅の代用、`--ball mlb` は MLB（ロジン、縫い目 0.80 mm）です。

| 項目 | NPB（既定） | MLB | 役割 |
| --- | --- | --- | --- |
| 質量 | 145.25 g | 同じ | 代用。規格 141.7–148.8 g の中点。サンプル平均は未入手 |
| 周囲 | 9.125 in | 同じ | 代用。規格 9–9.25 in の中点 |
| 縫い目の高さ | 0.90 mm | 0.80 mm | NPB は規格の標準。MLB は 72 球の平均 |

| 縫い目ありの μ | 1.0165（無塗布、既定） | 1.107（ロジン） | NPB＋ロジンの代用は 1.2910 |

| 縫い目の曲線 | Bourke | Bourke | 代用。どちらの公式球の中心線も公開されていない |

フォーシームの向きは、ヨーを探した角度ではなく、指の位置から置いています。人差し指と中指の指先は馬蹄の同じ脚の上にあり、縫い目は指を横切り、馬蹄の閉じた側は親指、親指は革の上です。出典は MLB.com の用語集、efastball、Steven Ellis、Wikipedia、RPP です。指先の間隔は 19.4 mm で、Jung ら（2015）の成人男性 DIP 幅（人差し指 18.8 mm、中指 18.6 mm）で指が接する間隔に近いです。もう一方の脚は、この向きでは指腹の外です。パッドを馬蹄の中央に置くと両脚は半幅 9.4 mm に入りますが、その投球は回転 1534 rpm、左右 −4.6° だったので採用していません。閉じた側を親指に向けるのは efastball の主たる説明で、逆も指導されています。

軟部は人差し指と中指です。指先の球に加え、指の長さ方向（先端から約 5–12 mm）にノードを置いています。半径 1.55 mm、1.0 mm 出て、約 4 N で底打ちします。フォーシームだけ、その下に革に触れるカプセル（半径 4.5 mm）があります。チェンジアップではこのカプセルが球を投げの線から外すので、付けていません。

運びの間、球は掌の姿勢に置き、パッドの表面に座らせ、球の接触は切ります。溶接した球に指がめり込むと、その力が肩に出ます（接触を残すと 1.54 倍、切ると 1.44 倍）。ロールが始まった瞬間に接触を戻します。指の位置サーボは、運びの間は握りの角度のままです。目標を革の向こうに置くと、球が逃げるたびに指が閉じ、球が手から歩いて出ます。

いまの 1 球の数値は上の判定表です。下の 1945 rpm は、連鎖と筋上限を入れる前の記録です。この握りでその時点の NPB 球を投げると、回転は 1945 rpm です。上限をかける前は 2164 rpm で、名目の数値 7 項目が合格でした。セットから着地までを足したあとも、要求トルクの尺屈は 68 N·m のままです。指先は縫い目の上にあります。1945 rpm は 2100–2500 rpm の下です。ロールのあいだ肘と手首は位置サーボではなく、球なしの参照トルクを筋の上限で切った値で動きます。手首伸展は Barrentine の平均に近い 41.5° です。

指の力は、1 kHz で人差し指 476 N、中指 399 N です。人差し指はせん断が主で、帯の外です。連鎖の前は 337 N と 269 N でした。肘の要求トルクは伸展 210 N·m で、かけているのは 52 N·m です。接触の時定数の 2 ms と 8 ms は連鎖の前に測り、合力は帯に入らなかったので、既定の 4 ms は動かしていません。上限は記録ではなく、ロール窓で実際にかけています。

## 次にやるとよいこと

- 運動連鎖は映像に出ます。リリース窓の速度積は変わりません。尺屈の要求は 67.8 N·m、肘の伸展要求は 210 N·m で、箱（11.9 と 52）の外です。指のせん断は 337 N から 476 N へ増えました。成人の、指が球に残る約 8 ms の手首モーメントは未入手です。`FEASIBLE_RELEASE` は掌をプレートから外すので、戻していません。
